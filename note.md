#### (2) 수도 코드

```Python
dist[start] = 0 #dist[0] = 0
dist[start를 제외한 모든 다른 노드] = limit (무한대) # dist[1:] = limit
visited[모든 노드] = False # visited[:] = False

while 방문하지 않은 노드가 존재 :
    # 1. 방문하지 않은 노드 중 dist가 가장 작은 노드 선택 (표의 "min")
    cur = visited가 False인 노드 중 dist[cur]가 최소인 노드

    if dist[cur] == limit :
        break  # 남은 노드에 도달 불가능

    visited[cur] = True  # 표의 "X" 처리

    # 2. cur과 연결된 인접 노드들의 거리 갱신 (표의 "+" 계산, min으로 갱신)
    for neighbor, weight in cur의 인접 노드들 :
        if visited[neighbor] == False:
            new_dist = dist[cur] + weight
            if new_dist < dist[neighbor] :
                dist[neighbor] = new_dist

# 종료 후 dist[]에는 start로부터 각 노드까지의 최단 거리가 저장됨
```

- 표의 각 행 = while문 한 번의 반복(iteration)
- **min** 표시 = 다음 반복에서 선택될 `cur` 노드
- ~~취소선~~ = 더 큰 값으로 갱신되어 버려진 이전 거리
- **X** = `visited[cur] = True` 처리된 노드
